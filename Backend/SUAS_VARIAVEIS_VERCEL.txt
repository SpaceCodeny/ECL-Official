🔧 COMO ADICIONAR NA VERCEL:

1. Acesse seu projeto na Vercel
2. Settings → Environment Variables
3. Para cada variável:
   - Clique em "Add New"
   - Cole o Name
   - Cole o Value
   - Selecione os ambientes (Production recomendado)
   - Clique "Save"
4. Após adicionar todas, faça um novo deploy ou redeploy
