📊 COMO OBTER DATABASE_URL (Supabase):

1. Acesse https://supabase.com
2. Abra seu projeto
3. Settings → Database → Connection string
4. Copie "Connection pooling" (porta 6543) para DATABASE_URL
5. Copie "Connection string" (porta 5432) para DIRECT_URL
6. Substitua [PASSWORD] pela senha real do projeto!

Exemplo:
DATABASE_URL=postgresql://postgres.abc123:[SUA_SENHA]@aws-0-sa-east-1.pooler.supabase.com:6543/postgres?pgbouncer=true
DIRECT_URL=postgresql://postgres.abc123:[SUA_SENHA]@aws-0-sa-east-1.pooler.supabase.com:5432/postgres

🔐 GERAR JWT SECRETS SEGUROS:

Use um dos métodos abaixo para gerar secrets aleatórios:

# Método 1: OpenSSL (Linux/Mac/Windows com Git Bash)
openssl rand -base64 32

# Método 2: Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

# Método 3: PowerShell (Windows)
[Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Minimum 0 -Maximum 256 }))

# Método 4: Site online (https://www.random.org/strings/)
Length: 32, Digits, Upper, Lower, Generate

Gere 2 secrets diferentes (um para ACCESS, outro para REFRESH)!

📝 NOTAS IMPORTANTES:

• DATABASE_URL deve usar porta 6543 (connection pooling)
• DIRECT_URL deve usar porta 5432 (migrations)
• JWT secrets devem ter no mínimo 16 caracteres (recomendado: 32+)
• CORS_ORIGINS deve incluir o domínio do frontend (separados por vírgula)
• Supabase permite conexões de qualquer IP por padrão
• Deploy automático acontece a cada push para main
• Cold start pode levar 2-5 segundos na primeira requisição
• Logs em tempo real: vercel logs --follow
