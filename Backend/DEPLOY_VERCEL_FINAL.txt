📝 COMO ADICIONAR NA VERCEL:

PASSO A PASSO:

1. Acesse: https://vercel.com/dashboard
2. Selecione seu projeto (ou crie novo se ainda não existe)
3. Vá em: Settings → Environment Variables
4. Para cada variável acima:
   
   a) Clique em "Add New"
   b) Name: cole o nome (ex: DATABASE_URL)
   c) Value: cole o valor completo
   d) Environments: selecione "Production" (ou todos)
   e) Clique "Save"

5. Repita para TODAS as variáveis obrigatórias (1 a 4)
6. Adicione as recomendadas (5 a 11) ajustando APP_URL e CORS_ORIGINS

🆘 TROUBLESHOOTING:

❌ Erro: "DATABASE_URL is required"
   → Verifique se adicionou a variável na Vercel
   → Confirme que selecionou "Production" environment

❌ Erro: "Can't reach database"
   → Verifique se a senha está correta
   → Confirme que copiou a URL completa (incluindo ?pgbouncer=true)
   → Projeto Supabase pode estar pausado (acesse o dashboard para despertar)

❌ Erro: Cold start timeout
   → Aumente maxDuration em vercel.json (já está em 30s)
   → Otimize imports pesados

❌ CORS Error
   → Adicione o domínio do frontend em CORS_ORIGINS
   → Separe múltiplos domínios por vírgula (sem espaços)

❌ 404 em todas as rotas
   → Verifique se Root Directory = Backend
   → Confirme que vercel.json está na raiz do Backend
