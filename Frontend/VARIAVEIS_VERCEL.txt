══════════════════════════════════════════════════════════════
  VARIÁVEIS DE AMBIENTE PARA VERCEL - FRONTEND
══════════════════════════════════════════════════════════════

Cole estas variáveis na aba "Environment Variables" do seu 
projeto na Vercel:

──────────────────────────────────────────────────────────────

NEXT_PUBLIC_API_URL=https://ecl-backend-six.vercel.app/api/v1
NEXT_PUBLIC_WS_URL=https://ecl-backend-six.vercel.app
NEXT_PUBLIC_ENV=production

──────────────────────────────────────────────────────────────

⚠️  IMPORTANTE:
- Marque todas como "Production", "Preview" e "Development"
- Após adicionar, faça um novo deploy para aplicar
- Variáveis com NEXT_PUBLIC_ são expostas ao cliente

──────────────────────────────────────────────────────────────

📝 CONFIGURAÇÕES DO PROJETO:

Framework Preset: Next.js
Root Directory: Frontend
Build Command: npm run build
Output Directory: .next
Install Command: npm install
