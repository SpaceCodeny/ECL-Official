# ==========================================
# TROUBLESHOOTING
# ==========================================

❌ "Token inválido" no login
→ Verificar se JWT_SECRET está definido
→ Limpar localStorage e tentar novamente

❌ Super Admin não consegue fazer login
→ Verificar SUPER_ADMIN_USERNAME e SUPER_ADMIN_PASSWORD_HASH
→ Conferir se hash está correto

❌ Admin criado desaparece
→ Normal em serverless (memória)
→ Recriar admin via interface
→ Para produção: implementar banco de dados

❌ "Acesso negado" ao tentar criar sessão como Super Admin
→ Comportamento correto!
→ Super Admin NÃO pode criar sessões
→ Criar um admin e usar esse para criar sessões
